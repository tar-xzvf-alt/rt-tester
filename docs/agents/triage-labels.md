# Triage labels

| Role / local label | Meaning |
|---|---|
| `needs-triage` | Maintainer needs to evaluate the incoming issue |
| `needs-info` | More information is required from the reporter |
| `ready-for-agent` | The issue is specified sufficiently for implementation |
| `ready-for-human` | Implementation requires a human |
| `wontfix` | The issue will not be implemented |

Tasks produced from an agreed specification are already implementation-ready;
triage applies to incoming reports and requests.
