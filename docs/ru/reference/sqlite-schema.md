# Схема SQLite сеанса GPIO

[English](../../reference/sqlite-schema.md)

`src/pc-receiver/database.py` создаёт схему и применяет изменения совместимости.
GPIO — ввод/вывод общего назначения. Старые базы могут содержать устаревшие
столбцы/таблицы или неполные метаданные. Проверяйте саму базу, а не определяйте
её версию по имени файла.

## `groups`

Одна строка на группу Arduino, уникальная по `session_id/group_index`:

```text
id, session_id, group_index
pc_timestamp, pc_timestamp_us, arduino_timestamp
jitter_us, delay_us, measurements_per_group, worst_count
requests_sent, responses_received, timeout_count
target_board, target_kernel, target_stress, target_payload
created_at
```

`pc_timestamp_us` — время ПК в микросекундах Unix, зафиксированное в начале
обработки группы. `pc_timestamp` — отдельно полученная строка местного календарного
времени при записи в базу, после запросов метрик и журналирования. Это не другое
представление того же момента: отметка может быть существенно позже.
`arduino_timestamp` берётся из `millis()` прошивки, а не из времени Unix.
`delay_us` хранит настроенный интервал запросов.
`jitter_us` — стандартное отклонение генеральной совокупности задержек **всех
полученных ответов** группы. Вычисленное прошивкой среднее всей группы
`mean_latency_us` **не сохраняется** в этой таблице.

Для текущих данных проверяйте `requests_sent = responses_received + timeout_count`.
Устаревшие счётчики или нули по умолчанию не доказывают отсутствие потерь запросов.

## `latencies`

```text
id, group_id, latency_us, rank_in_group
```

Сохраняются только отобранные образцы худшего хвоста, ранжированные по убыванию.
Хвост — наибольшие задержки среди полученных ответов. `group_id` ссылается на
`groups.id` с каскадным удалением. Размер хвоста ограничен числом ответов;
у группы без ответов нет строк задержек. Средние, минимумы и процентили этой
таблицы описывают хвост, а не всю группу. Тайм-ауты не добавляются как образцы
задержки. См. [статистику измерений](measurement-statistics.md).

## `events`

```text
id, session_id, event_type
event_time, event_time_us, time_since_start_us
group_index, details, created_at
```

Регистрирует жизненный цикл сеанса и события обнаружения пропавших групп и
восстановления. Перед интерпретацией запуска изучите события помимо обычных
`start`/`stop`.

## `soc_metrics`

```text
id, session_id, group_index, pc_timestamp
cpu_percent, memory_percent, cpu_max, mem_max
cpu_avg, mem_avg, samples_in_group, duration_ms, created_at
```

Сводки по группам, полученные запросами к Prometheus, для SoC (системы на кристалле).
Их наличие и число образцов зависят от доступности мониторинга; отсутствие
данных не означает нулевую нагрузку целевой системы.

## `trace_group_metrics`

```text
id, session_id, group_index, host, stage
count, min_us, avg_us, max_us, created_at
```

Импортированные агрегаты этапов режима с супервизором, уникальные по
сеансу/группе/узлу/этапу. Это агрегаты, а не исходные трассировки каждого запроса.
Утилита объединения, доступная только из исходников, не копирует эту таблицу;
сохраняйте исходные базы режима с супервизором и исходные трассировки.

## `schema_version`

```text
version, applied_at
```

Зарезервирована, но сейчас **не используется** для автоматического учёта версии:
код создаёт таблицу, но не записывает и не проверяет версию схемы. Она не связана
с версионируемым манифестом комплекта cyclictest.

SQLite — первичные данные GPIO/режима с супервизором. Панели и отчёты —
производные представления. Используйте [проверки целостности приёмника](../usage/receiver.md)
и [анализ](../usage/analysis-and-reports.md), сохраняя сведения о происхождении рядом.
