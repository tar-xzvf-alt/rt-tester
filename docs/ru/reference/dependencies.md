# Зависимости и установка

[English](../../reference/dependencies.md)

## Управляющий ПК с ALT Linux

Стандартный способ проведения измерений использует установленный RPM-пакет:

```bash
apt-get install rt-tester-tools
```

Для этого нужен настроенный репозиторий пакетов с `rt-tester-tools` и его
зависимостями. Наличие пакетов проекта и архитектурно-зависимых пакетов целевой
системы в каждом репозитории ALT не предполагается. Если вы получили локальный
RPM, проверьте поддержку установки из локального файла в установленном ALT APT
(`apt-get --help` и руководство), затем укажите фактическое имя полученного файла:

```bash
apt-get install ./rt-tester-tools-VERSION-RELEASE.noarch.rpm
```

Если эта версия APT не принимает локальные RPM, используйте поддерживаемый вашим
дистрибутивом способ их установки. Локальный RPM не предоставляет недостающие
зависимости: для них всё равно нужны совместимые репозитории или отдельные RPM.
Не отключайте проверку зависимостей ради видимости успешной установки.

Пакет объявляет зависимости от Python 3, `python3-module-serial`,
`python3-module-requests`, `openssh-clients`, `rsync` и `coreutils`.
Для сценариев запуска необходима неинтерактивная аутентификация SSH по ключу
(SSH — протокол защищённого удалённого доступа). Используйте `--help`
установленных команд для проверки интерфейса установленной версии.

Prometheus и Grafana — дополнительное ПО на ПК для локального или центрального
мониторинга; при базовом сборе GPIO их запуск отключают параметрами
`--no-prometheus --no-grafana`. GPIO — линии ввода/вывода общего назначения.
Центральный мониторинг также требует **локального Prometheus** для опроса
метрик и запросов, но использует серверную Grafana через перенаправление SSH.

Построение графиков и объединение баз сейчас доступны только из исходного кода.
Получите рабочую копию репозитория и установите совместимые pandas, numpy и
matplotlib. В ALT обычно используются пакеты `python3-module-pandas`,
`python3-module-numpy` и `python3-module-matplotlib`; проверьте их наличие в своём
репозитории. Приёмнику из исходного кода также нужны serial и requests.
Сборка из исходников и упаковка описаны в разделе
[разработки и тестирования](../development/development-and-testing.md).

## Целевая система автономного GPIO

Если репозитории целевой системы предоставляют совместимые пакеты:

```bash
apt-get install rt-handler prometheus-node_exporter openssh-server
```

Сценарий автономного запуска требует исполняемый файл `node_exporter` **и
работающий процесс даже при отключённом мониторинге**: он проверяет программу
и закрепляет её потоки с обычным планированием за ядрами обслуживания.
Включите и запустите её через настройки службы целевого пакета, затем проверьте
перед сбором. Планирование, привязка к ядрам, доступ к GPIO и необязательное
изменение частот требуют подходящих привилегий.

Внешний пакет `rt-handler-0.1.8-alt1` объявляет зависимости `linux-rt-tests` и
`stress-ng`. Профили обработчика в пространстве ядра требуют модуль ответчика,
соответствующий работающему ядру; пакет для Linux 6.18 называется
`kernel-modules-rt-gpio-responder-6.18`. Наличие и установка определяются проектом
[rt-handler-kernel](https://altlinux.space/besogon1238/rt-handler-kernel), а не
этим репозиторием. См. [GPIO целевой системы](../hardware/target-gpio.md).

## Целевые системы режима с супервизором

Платам среды исполнения/супервизора и контроллера нужны соответствующие внешние
пакеты `rt-supervisor` и `rt-controller`, SSH, привилегии для сырых сокетов/GPIO
и настроенная интеграция среды исполнения. Пример среды исполнения поставляется
в `rt-supervisor-runtime-example`; промышленные ПЛК (программируемые логические
контроллеры) предоставляют собственную среду исполнения. Полные запуски с
мониторингом требуют экспортёры трассировок и `node_exporter` на узле среды
исполнения. Для нагрузки нужен `stress-ng` на этом узле. Предварительные проверки
и топология описаны в [режиме с супервизором](../modes/supervised-raw-ethernet.md).

## Целевая система cyclictest

```bash
apt-get install linux-rt-tests openssh-server
# Stressed scenarios only:
apt-get install stress-ng
```

Планирование реального времени и закрепление памяти требуют соответствующих
разрешений на целевой системе.

## Arduino и сервер

Прошивка Arduino Mega 2560 поставляется отдельно от RPM для ПК. Ей нужны ядро
Arduino AVR, инструменты AVR и ArduinoJson; см.
[подготовку Arduino](../hardware/arduino.md).

Центральному серверу мониторинга нужны Prometheus с поддержкой приёма remote write
(удалённой записи метрик), Grafana и учётная запись/ключ SSH для перенаправления.
См. [настройку сервера](../observability/central.md). Каталог cyclictest дополнительно
требует внешний импортёр/каталог `rt-results`, а для панели SQLite —
`grafana-plugin-frser-sqlite-datasource`. Эти пакеты и настройки относятся к
`rt-results`; ни RPM для ПК, ни remote write их не устанавливают.
