# Протокол проверки документации

[English](../../reference/validation.md)

Этот протокол отделяет проверки документации от аппаратных измерений.
Эталонная пошаговая инструкция — выполнимая процедура для проверки на подготовленном
стенде, а не утверждение, что новый эталонный запуск уже проведён.

## Подготовительные проверки

| Проверка | Состояние | Подтверждение |
|---|---|---|
| Существующие автоматические тесты поведения | Пройдены до переработки | 38 тестов на исходной версии `5f05a38` |
| Обновлённый автоматический набор | Пройден | 43 теста, включая двуязычные примеры и эталонные профили |
| Локальные ссылки и ресурсы английской/русской документации | Пройдены | Набор unittest для документации; внешние URL и якоря не проверяются |
| Адаптация/генерация примеров профилей | Пройдена | Изолированные тесты конфигурации; жизненный цикл сценариев запуска не выполнялся |
| Документированный синтаксис CLI (интерфейса командной строки) | Справка изучена | Пути установленных команд-обёрток проверяются статически; справка CLI из исходников запускалась |
| Статистические определения | Исходники проверены | Алгоритм всей группы/хвоста в прошивке и хранение SQLite |
| Статистика исторического примера | Выполнено, только чтение | Сеанс `186819`: 2500 групп, 187500 строк хвоста, среднее 164.679701 мкс, максимум 348 мкс |
| Построение исторических графиков из исходников | Выполнено | Код создания копии и команда latency из инструкции создали PNG; SHA256 исходной базы не изменился |
| Исторический SVG | Проверен | Все 25 точек проверены по агрегатам SQL исходной базы |
| Код проверки целостности эталонного примера | Выполнен на синтетических данных | 100 групп без потерь и 7500 строк хвоста; это не аппаратный результат |
| Сборка и загрузка аппаратной прошивки | Не выполнялось | Требуются Mega, инструменты AVR и стенд |
| Установка эталонного RPM и запуск GPIO | Не выполнялось | Требуются целевые пакеты, проводка и потоковый IRQ (обработчик аппаратного прерывания) |
| Пошаговая проверка локальных Prometheus/Grafana | Не выполнялось | Требуются установленное ПО мониторинга и действующий сбор |
| Центральная доставка метрик | Не выполнялось | Требуются сервер/учётная запись и подтверждённое получение соответствующего сеанса |
| Сборка/установка RPM выпуска | Фиксируется отдельно | Готовая документация одобрена; результаты упаковки приведены в отчёте об артефактах и журналах сборки |

## Проверки завершения сценариев — 2026-10-09

- Полный автоматический набор: **69 тестов пройдено**, включая 19 тестов очистки.
- Ошибки запуска GPIO/stand, независимые завершающие действия, сохранение
  прерываний, отказ вывода предупреждений и сохранность bundle cyclictest
  проверены через точки входа сценариев с подменённым SSH и временными файлами.
- Локальные shell-имитации проверили ошибки сигналов, сохранение PID-файлов,
  рабочие процессы группы после выхода лидера, обработку зомби и запрет удаления
  каталога cyclictest с PID-файлом. Реальным процессам плат сигналы не отправлялись.
- Реальные короткие локальные дочерние процессы проверили успешный стартовый шлюз,
  закрытый stdin, завершение receiver, игнорирующего TERM, и прерывание очистки.
- Справка CLI GPIO/stand/cyclictest из исходников и `git diff --check` пройдены.
- Удалённая очистка SSH, фактическое поведение групп supervisor/runtime,
  аппаратура GPIO и сборка/установка RPM для этого изменения не выполнялись.

## Контрольный список приёмки стенда

Для каждой выполненной проверки записывайте дату, пакеты/ревизии, ревизию платы,
конфигурацию ядра, версии инструментов/библиотек прошивки, электрическую схему
соединений/уровни, настройки CPU (процессора)/регулятора частоты и фактический профиль.

1. Установите RPM на ПК и необходимые целевые пакеты; изучите справку команд.
2. Соберите/загрузите прошивку и проверьте доступ к последовательному порту на 115200.
3. Проверьте соответствие контактов целевой платы, согласование уровней, общий
   GND (землю) и независимые линии запроса/ответа; подтвердите привязку и
   планирование обработчика/IRQ.
4. Выполните базовую короткую проверку из трёх групп: 4500 запросов/ответов,
   ноль тайм-аутов, группы 0–2, 225 сохранённых строк.
5. Выполните сбор 100 групп: 150000 запросов/ответов, ноль тайм-аутов,
   группы 0–99, 7500 сохранённых строк; изучите события и диагностику.
6. Проанализируйте сохранённую базу и проверьте статистическую совокупность графика.
7. Выполните локальный мониторинг: проверьте точки доступа, оба задания опроса,
   метрики соответствующего сеанса, источник данных/переменные Grafana и очистку.
8. Выполните центральный мониторинг: проверьте перенаправления SSH (защищённого
   удалённого доступа), приёмник remote write (удалённой записи метрик),
   соответствующий сеанс с меткой сборщика на принимающей стороне, панель
   и опустошение очереди перед очисткой.

Неудачный или невыполненный шаг остаётся видимым в протоколе. Исправный туннель
или снимок панели сам по себе не подтверждает целостность измерений или доставку
всех групп. При изучении исторических данных отмечайте недоступные счётчики/версии
как неизвестные, а не применяйте текущие критерии приёмки без потерь задним числом.
