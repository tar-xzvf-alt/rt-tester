# Документация RT Tester

[English](../README.md)

RT Tester измеряет задержку (latency) отклика систем: время от запроса до ответа,
в том числе по GPIO — линиям ввода-вывода общего назначения. PREEMPT_RT — конфигурация
вытеснения Linux для работы в реальном времени; сама по себе она не гарантирует
соблюдение предельного времени отклика.

## Маршрут инженера-экспериментатора

Начните с [первых шагов](getting-started.md), затем перейдите к

Prometheus обеспечивает оперативный мониторинг, а не публикацию базы данных.
Исторические отчёты фиксируют прежние условия и не заменяют актуальные инструкции
по установке и подключению.

## Сопровождение документации

Канонические документы на английском языке находятся по существующим путям.
Русские версии пользовательских документов находятся в `ru/`; команды, определения,
ограничения и ссылки переключения языка следует обновлять согласованно.
README должен оставаться кратким и ориентированным прежде всего на инженера.
У каждого режима одно основное руководство; рабочие процедуры размещаются в
`usage/`, управление условиями эксперимента — в `methodology/`, форматы и пути —
в `reference/`, численные результаты с датами — в `results/`.
Инструкции по работе не должны зависеть от частных имён узлов и авторских путей.
Протоколы проверки отделяют статические и автономные проверки от физических
измерений и проверок работы с серверами.
