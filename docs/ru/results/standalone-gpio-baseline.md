## Опорные сеансы с супервизором

Текущий запуск с супервизором при этой проверке был невозможен: на
`visionfive2 end0` отсутствовал физический линк (`/sys/class/net/end0/carrier = 0`),
поэтому `bvcarm` по адресу `10.43.0.2` был недоступен. Для сравнения использовали

## Интерпретация

Базовый автономный GPIO даёт среднюю задержку около `0.44 мс` при выбранных
параметрах Arduino. Опорные сеансы с супервизором через сырые кадры Ethernet
дают среднюю задержку около `17.9-18.8 мс` при той же модели сохранённых строк
худших задержек.

Сравнение с новым запуском режима с супервизором следует повторить после
восстановления физического линка
`visionfive2 end0 <-> runtime/controller peer` (узел среды исполнения/контроллера).

Отчёт не устанавливает контролируемое одновременное сравнение: сеансы с
супервизором — более ранние опорные данные. 500 сохранённых строк в 100 группах
описывают выбранный хвост (наибольшие задержки), а не всю совокупность ответов.
Сохраняйте числовые значения как датированные данные и обращайтесь к
[текущей методике](../methodology/gpio-measurements.md) для нового сравнения.
