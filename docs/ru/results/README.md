# Указатель результатов

[English](../../results/README.md)

Это исторические отчёты, а не результаты, собранные при подготовке текущей
документации. Для нового эксперимента используйте руководство режима и методику;
проверяйте текущее ПО, проводку и профили перед повторным использованием команды
из отчёта.

| Отчёт | Плата/ядро | Сценарий |
|---|---|---|
| [Базовое сравнение автономного GPIO](standalone-gpio-baseline.md) | автономные платы | базовый результат в сравнении с прежними сеансами с супервизором |
| [VisionFive 2 без RT](visionfive2-userspace-vs-kernelspace-non-rt.md) | VisionFive 2 без RT | пользовательское пространство и пространство ядра, без нагрузки/с нагрузкой |
| [VisionFive 2 PREEMPT_RT](visionfive2-userspace-vs-kernelspace-preempt-rt.md) | VisionFive 2 PREEMPT_RT | пользовательское пространство и пространство ядра, сравнение ядер |

GPIO — ввод/вывод общего назначения; PREEMPT_RT — конфигурация Linux с вытеснением
для реального времени (RT). Некоторые отчёты указывают локальные пути артефактов,
не включённых в RPM или репозиторий. Они документируют происхождение, а не файлы,
доступные на вашей машине. Записанные профили, версии и методика описывают
известные условия; недостающие сведения о прошивке/обработчике/ядре ограничивают
воспроизводимость и должны оставаться явно отмеченными.
Числовые сводки задержек описывают сохранённые образцы худшего хвоста (наибольших
задержек), если не указано иное; джиттер описывает разброс всей полученной группы.
См. [статистику измерений](../reference/measurement-statistics.md).

Историческую базу под контролем версий и график, используемые в текущем маршруте
анализа, см. в [автономной пошаговой процедуре](../usage/standalone-gpio-walkthrough.md).
